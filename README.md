# 🚀 LinkedIn Tech Automation (Node.js & Gemini AI)

Uma automação desenvolvida em **Node.js** que utiliza a inteligência artificial do **Google Gemini** (`gemini-3.5-flash-lite`) para gerar dinamicamente conteúdos profissionais e publicá-los automaticamente no **LinkedIn**, incluindo suporte para upload de imagens e links de contexto reais.

---

## 🛠️ Tecnologias Utilizadas

- **Node.js**
- **Google GenAI SDK** (`@google/genai`)
- **LinkedIn REST API v2** (UGC Posts & Images)
- **Dotenv** (Gestão segura de variáveis de ambiente)

---

## ⚙️ Pré-requisitos

Antes de executar o projeto, certifique-se de que tem instalado no seu sistema:

- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- Uma conta de programador no LinkedIn com uma aplicação configurada (para obter o `CLIENT_ID` e `CLIENT_SECRET`).
- Uma chave de API do Google Gemini.

---
